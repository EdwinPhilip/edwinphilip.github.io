# Engineering Knowledge Base

A growing collection of practical engineering study guides for engineers who want to understand how systems behave in production.

The guides cover first principles, technical diagrams, production commands, architecture trade-offs, hypothetical incidents and challenging interview questions. Examples are illustrative unless a source is explicitly cited.

## Available

### [Networking Fundamentals — Module 1](/guides/networking/)

Eight chapters covering complete requests, TCP, DNS, TLS, load balancing, CIDR/NAT, Kubernetes/GKE networking and incident troubleshooting.

### [Linux Internals & Resource Management — Module 2](/guides/linux-internals/)

Seven in-depth chapters on processes, virtual memory, cgroups and OOM, CPU throttling, storage/durability, file descriptors, and Linux incident response; includes [35 challenging follow-ups](/guides/linux-internals/follow-ups).

### [Kubernetes Architecture & Production Operations — Module 3](/guides/kubernetes/)

Twelve in-depth chapters covering Kubernetes control-plane internals, etcd, scheduler, controllers, workload lifecycles, resources and QoS, storage/CSI, autoscaling, RBAC, admission and upgrades; includes [six labs](/guides/kubernetes/labs) and [42 challenging follow-ups](/guides/kubernetes/follow-ups).

### [Terraform Architecture, Internals, AWS and GCP · Module 4](/guides/terraform/)

Twelve in-depth chapters covering Terraform execution, state, modules, AWS/GCP infrastructure, cloud identity, import/refactoring, drift recovery, security and CI/CD. Includes [45 senior follow-ups](/guides/terraform/follow-ups) and [eight labs](/guides/terraform/labs).
