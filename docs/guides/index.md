# Engineering Knowledge Base

A growing collection of practical engineering study guides for engineers who want to understand how systems behave in production.

The guides cover first principles, technical diagrams, production commands, architecture trade-offs, hypothetical incidents and challenging interview questions. Examples are illustrative unless a source is explicitly cited.

## Available

### [Networking Fundamentals — Module 1](/guides/networking/)

Eight chapters covering complete requests, TCP, DNS, TLS, load balancing, CIDR/NAT, Kubernetes/GKE networking and incident troubleshooting.

### [Linux Internals & Resource Management — Module 2](/guides/linux-internals/)

Seven in-depth chapters on processes, virtual memory, cgroups and OOM, CPU throttling, storage/durability, file descriptors, and Linux incident response; includes [35 challenging follow-ups](/guides/linux-internals/follow-ups).

### [Kubernetes Architecture & Production Operations — Module 3](/guides/kubernetes/)

Twelve in-depth chapters covering Kubernetes control-plane internals, etcd, scheduler, controllers, workload lifecycles, resources and QoS, storage/CSI, autoscaling, RBAC, admission and upgrades; includes [six labs](/guides/kubernetes/labs) and [42 challenging follow-ups](/guides/kubernetes/follow-ups).

### [Terraform Architecture, Internals, AWS and GCP · Module 4](/guides/terraform/)

Twelve in-depth chapters covering Terraform execution, state, modules, AWS/GCP infrastructure, cloud identity, import/refactoring, drift recovery, security and CI/CD. Includes [45 senior follow-ups](/guides/terraform/follow-ups) and [eight labs](/guides/terraform/labs).

### [Google Cloud Fundamentals and Production Engineering · Module 5](/guides/gcp/)

Eight comprehensive chapters covering GCP hierarchy, identity and federation, Shared VPC, NAT/DNS/load balancing, Compute Engine, storage/data, observability, and high-availability architecture. Includes [eight practical labs](/guides/gcp/labs) and [40 senior follow-ups](/guides/gcp/follow-ups).

### [GKE Architecture, Networking and Production Operations · Module 6](/guides/gke/)

Eight in-depth chapters on GKE control plane, Standard/Autopilot, node scheduling, VPC-native networking/eBPF, Ingress/Gateway/NEGs, workload identity, CSI, autoscaling, upgrades and incident recovery. Includes [eight labs](/guides/gke/labs) and [40 difficult follow-ups](/guides/gke/follow-ups).

### [Cloud Architecture, Reliability & System Design · Module 7](/guides/reliability/)

Eight in-depth chapters covering SLIs/SLOs, high availability, failure domains, backpressure, durable transaction correctness, multi-region disaster recovery, capacity, data-layer resilience and incident leadership. Includes [40 difficult follow-ups](/guides/reliability/follow-ups) and [seven hands-on labs](/guides/reliability/labs).

### [CI/CD, GitOps & Platform Engineering · Module 8](/guides/platform-engineering/)

Eight chapters on trusted builds, GitOps reconciliation, progressive delivery, supply-chain security, federated identity, internal developer platforms, observability and multi-cluster governance. Includes [40 difficult follow-ups](/guides/platform-engineering/follow-ups) and [eight hands-on labs](/guides/platform-engineering/labs).

### [Python and Shell Automation · Module 9](/guides/python-automation/)

Six consolidated chapters covering Python collections, JSON/log/CSV parsing, time windows, safe API pagination, testable command-line tools and practical Bash/`jq`/`awk` processing. Includes [six labs](/guides/python-automation/labs) and [36 challenging follow-ups](/guides/python-automation/follow-ups).

### [AI-Assisted Engineering: ADE and Plan–Build–Review · Module 10](/guides/ai-assisted-engineering/)

Eight in-depth chapters on understanding coding requirements, plan/build/review workflows, agent permissions, independent correctness checks, multi-file changes and evidence-based handoffs. Includes [eight labs](/guides/ai-assisted-engineering/labs) and [40 challenging follow-ups](/guides/ai-assisted-engineering/follow-ups).

## Learning path

Modules 1–10 cover networking, Linux, Kubernetes, infrastructure as code, cloud platforms, reliability, platform engineering, practical automation and AI-assisted development.
